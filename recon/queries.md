# High-yield search query patterns (short, distinct)
- Official: `<product> docs <feature>` · `site:github.com <lib> <error>` · `<lib> changelog <version>`
- Error: exact error string in quotes, minus paths/IDs
- Comparison: `<A> vs <B> benchmark <year>` then fetch both official docs
- Pricing/limits: `<product> pricing` / `<product> rate limits` → fetch the official page only
- Papers: `arxiv <topic> survey <year>` · `<method> ablation`
- Recency: add current year; for "latest" never use an old year
Fetch ≤2 pages per sub-question; extract facts to notes; drop the page.
