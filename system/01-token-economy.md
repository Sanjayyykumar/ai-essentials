# Token economy — do more with less
1. **Locate, then read.** `grep -rn`/`rg`/`find` first; open only matching ranges (±30 lines).
2. **Index files are the map.** `libraries/CATALOG.md` → one entry → one SKILL.md. Never load a whole library.
3. **Offline before online.** `libraries/offline/*` cheat sheets cover ffmpeg, SVG, CSS/GSAP motion, git, image prompts, research queries.
4. **Search smart (when online is needed):** 1–6 word queries, distinct per item, fetch the 1–2 best pages, extract facts to notes, discard page text.
5. **Write, don't paste.** Code >40 lines → file. Long logs → `tail -50` or grep errors.
6. **Batch.** Independent reads/searches/commands in one turn.
7. **Compress context.** After each phase, move findings into STATUS.md/PLAN.md and stop re-reading raw sources.
8. **Reuse.** Templates in `templates/`, scripts in `scripts/`, lessons in `system/LESSONS.md`.
9. **Stop rules.** 2 failed attempts at the same approach → change approach; 3 → report the blocker with evidence.
10. **Delegate only big fan-outs** (many independent files/sites) to sub-agents; give them a self-contained brief.
