# Logo + logo animation playbook
1. **Discovery:** name, meaning, audience, 3 adjectives, competitors (to stay distinct), usage (app icon? favicon? print?).
2. **Concepts (3):** wordmark · lettermark/monogram · symbol + wordmark. Sketch as simple SVG geometry.
3. **Refine:** optical balance, grid, 2-color max, test 16px/32px/512px, mono & reversed.
4. **Deliver kit:** `logo.svg`, `logo-mono.svg`, `logo-reversed.svg`, `icon.svg`, PNG 16–1024, favicon.ico, usage note (clearspace, min size, colors).
5. **Animate:** SVG stroke-draw (`stroke-dasharray`), mask reveal, morph between marks; 1.2–2.5 s; export as CSS/SVG, Lottie, and MP4/WebM (alpha via ProRes 4444 or WebM VP9).
Originality check: must not resemble any existing brand mark.
