# Design playbook (UI, landing, brand, poster)
1. **Brief:** audience, single goal, tone (3 adjectives), must-include content, format/size.
2. **System first:** palette (1 primary, 1 accent, neutrals; check AA contrast), type scale (2 families max, 1.25 ratio), 8-pt spacing, radius, shadow.
3. **Layout:** hierarchy = one focal point; grid (12-col web / 4-col mobile); generous whitespace.
4. **Build:** HTML/CSS (or the host's design tool). Diagrams → diagram-design skill.
5. **Critique pass:** hierarchy, consistency, accessibility, UX laws (Fitts, Hick, Jakob — e2e ux-laws).
6. **Deliver:** source + PNG/PDF export; tokens as CSS variables.
