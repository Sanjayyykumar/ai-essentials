# Content, docs & SEO playbook
1. Audience + goal + format. 2. Outline (H2s answer real queries). 3. Draft plain, specific, sourced. 4. Humanize pass (humanizer: remove AI tells — "delve", tricolons, em-dash spam, hedging). 5. SEO: one intent per page, title ≤60 chars, meta ≤155, internal links, schema, image alt (e2e seo-technical/seo-content/seo-local/seo-geo).
