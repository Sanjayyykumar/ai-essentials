# Default stacks (pick, don't debate)
- Static/marketing site: single HTML+CSS+JS, or Astro. Hosting: GitHub Pages / Netlify / Vercel.
- Web app: Vite + React + TS + Tailwind; API: Node (Fastify) or Java Spring Boot; DB: Postgres; auth: provider SDK.
- Mobile: Expo (React Native). Desktop: Tauri.
- Python tooling: uv + ruff + pytest. Java: Maven/Gradle + JUnit5.
- Testing: unit (vitest/pytest/JUnit) + e2e (Playwright).
- CI: GitHub Actions (lint → test → build).
